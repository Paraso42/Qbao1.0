# 高尔顿灯阵微信小程序

一个单球高尔顿板游戏。玩家投入弹珠并随机获得倍率；倍率越高，亮灯通道越少。小球经过亮灯通道即可获得 `投入弹珠 × 倍率` 的弹珠奖励。

## 在微信开发者工具中运行

1. 使用微信开发者工具导入本目录。
2. 点击“编译”即可运行。

项目已内置 Matter.js 运行文件，不需要在微信开发者工具中构建 npm。`package.json` 仅用于记录上游依赖版本。

`project.config.json` 默认使用测试 AppID `touristappid`。正式发布前请换成自己的小程序 AppID。

## 默认规则

| 倍率 | 亮灯数量 | 命中奖励 |
| --- | ---: | ---: |
| 1 倍 | 6 / 8 | 投入 × 1 |
| 2 倍 | 4 / 8 | 投入 × 2 |
| 3 倍 | 2 / 8 | 投入 × 3 |
| 5 倍 | 1 / 8 | 投入 × 5 |

所有弹珠均为小程序内虚拟道具，不包含充值、提现或现金兑换功能。
